Nhận vào máy — 01 · Khởi chạy

Chạy một lệnh, không cần cài đặt phức tạp.

Void-bit nằm sẵn tại thư mục products\void-bit trong bộ DrgX. Launcher tự động khởi chạy OJ server (nếu cổng 8080 đang chạy sẵn thì tự tái sử dụng), bật web học tập ở cổng 8000 và mở trình duyệt.

## Mở PowerShell tại thư mục gốc của DrgX
.\drgx.cmd oj                      # Hoặc: products\void-bit\run-oj.cmd

## Hoặc khởi chạy riêng từng dịch vụ khi cần debug:
products\void-bit\OJ\oj_server.exe --port 8080 --static static --problems problems
node products\void-bit\serve.js    # web học tập :8000

Lưu ý kỹ thuật: oj_server.exe dùng tham số cờ tường minh --port / --static / --problems (tài liệu README cũ ghi tham số theo vị trí đã được cập nhật lại chính xác).

Nhận vào máy — 02 · OJ Local Engine

Chấm trên máy thật — đo từng mili-giây, từng KB bộ nhớ.

Judge biên dịch và thực thi mã nguồn ngay trên máy, trả về chi tiết từng testcase: thời gian chạy (runtime_ms), bộ nhớ đỉnh (memory_kb đo qua Windows PSAPI) và điểm số theo từng subtask.

12/12
Probe AC — C++17
Bài ds_stack_009: 12 test / 3 subtask (20+30+50 điểm). Tổng thời gian gồm compile: 5,6 s; thời gian chạy thuần 670 ms.
12/12
Probe AC — Python 3
Đo trên cùng bài và cùng server: 2,0 s toàn tuyến; thời gian chạy thuần 1,61 s (áp dụng hệ số TL x3).
0/12
Bắt bài nộp rỗng
Nộp int main(){return 0;} → trả về WA cả 12/12 test kèm chi tiết input/expected/output.
8000+8080
Hai cổng độc lập
Cổng 8000: Web học tập tĩnh (Node). Cổng 8080: Giao diện "Local OJ — Codeforces Modern" gọi trực tiếp /api/judge.
✓Chấm điểm chuẩn Subtask thi HSG — bài toán chia 3 subtask (20 / 30 / 50 điểm); học sinh chỉ nhận điểm của một subtask khi vượt qua toàn bộ test thuộc subtask đó.
✓Đầy đủ 5 trạng thái AC / WA / TLE / RE / CE — trả về kèm trường compile_error chi tiết để học sinh sửa lỗi cú pháp ngay trên giao diện web.
✓REST API & SSE Stream mở — hỗ trợ GET /api/problems, POST /api/judge, /api/judge/stream (Server-Sent Events) và POST /api/reload.
Nhận vào máy — 03 · Đa ngôn ngữ

Hỗ trợ đa ngôn ngữ — công bằng về giới hạn thời gian.

Do đặc thù thông dịch của Python chậm hơn C++, Void-bit OJ cấp hệ số nhân thời gian riêng cho từng ngôn ngữ (Python x3, Java x2 theo tài liệu server) để học sinh dùng Python không bị TLE bất công.

Nhận vào máy — 04 · Tính minh bạch kỹ thuật

Anti-cheat Winnowing — đo lường cụ thể, không phóng đại.

Thay vì tuyên bố chung chung "chống sao chép 100%", Void-bit cung cấp thuật toán lấy dấu vân tay mã nguồn Winnowing chạy thật qua API, trả về tỷ lệ tương đồng để giáo viên xem xét quyết định.

Engine Winnowing thật: bài C++/Python bị đổi toàn bộ tên biến, tên hàm và chú thích vẫn đạt similarity 100% (flagged=true, ngưỡng 80%); hai lời giải khác thuật toán chỉ 15,8% (flagged=false). Tái kiểm chứng: python scripts/verify_winnowing.py.
